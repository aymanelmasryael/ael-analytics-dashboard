About AEL Analytics Dashboard

A pure SVG charting dashboard by AEL Digital Studio

📋 Overview

AEL Analytics Dashboard generates all charts as pure SVG — no external charting libraries. Features 5 chart types, interactive tooltips, data export/import, and real-time simulation.

⚡ Features

  • 5 chart types: Line, Bar, Pie, Area, Donut
  • Pure SVG generation — zero dependencies
  • Interactive tooltips on hover
  • KPI metric cards with trends
  • CSV import/export
  • Auto-refresh support

🛠 Tech Stack

  • HTML5 — Semantic structure
  • CSS3 — Glassmorphism, grid, animations
  • JavaScript — SVG DOM generation, data simulation, CSV parser
